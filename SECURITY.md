# Security

The public Lizz demo and the preserved original application have different boundaries. The public runtime is under `public-app/`. The original root application is not approved for public multi-tenant customer use.

## Reporting an issue

Report suspected issues privately to repository maintainers through existing access-controlled channels. Do not post credentials, personal records, mailbox content, or exploit details in public issues, screenshots, or social posts.

Include the affected component, reproduction steps using synthetic data, observed behavior, and potential impact. Never test against another person's records, mailbox, or financial accounts.

## Access and deployment

The live demo does not imply permission to publish the complete source tree or its history. Read the [sanitization report](docs/PRIVACY_AND_SANITIZATION_REPORT.md) before changing visibility or distributing source. Never copy old environment files into Vercel.

The [security documentation](docs/SECURITY.md) describes safeguards and limitations. The [implementation report](docs/IMPLEMENTATION_REPORT.md) records actual verification. No independent compliance certification or penetration-test result is claimed.
